## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Mallanagowda63/portfolio-Mallanagowda.git
   cd portfolio-Mallanagowda
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
